Axiom — Windows 后台自动化工具（预览版）

要求：Windows 11 x64。已包含 .NET 和所需 WinUI 运行依赖，无需另外安装。
便携版：解压整个文件夹，双击 Axiom.exe，按当前账户接受管理员权限请求。
安装版：运行 Axiom-…-setup.exe，安装后从开始菜单打开。
请保留 app 文件夹，它包含运行依赖。安装和便携版使用相同配置。

关闭窗口不停止自动化后台；如果正在“使用观察”，关闭窗口会立即结束观察。在设置中选择“停止后台并退出”才会停止。
升级或卸载前，请先正常退出受 Axiom 控制的游戏、等待恢复，再停止后台。
登录启动在 Axiom 的设置中启用；安装程序不会擅自启用。
移动文件夹或从便携版改用安装版后，已启用登录启动的用户需在设置中更新启动位置。

用户配置和活动日志位于 %USERPROFILE%\.axiom；卸载默认保留。
便携版指无需安装，不表示把个人配置放在程序目录。
本预览尚未完成全部性能、DPI、游戏和系统版本验收。

体验本次观察与建议功能：
1. 打开“使用观察”，选择范围、5 分钟和要排除的应用，点击开始。
2. 使用你愿意观察的测试应用；可暂停、继续、结束，也可补充本次目的。
3. 查看本地记录和建议。证据不足时可以没有建议，不会自动生成正在运行的规则。
4. “预览分析摘要”允许删减后复制给你选择的 AI；不需要 API Key，不自动上传。
5. AI 返回结构化 JSON 后用“导入 AI 建议”校验；确认后进入未保存、默认暂停的规则草稿，仍需审阅并保存启用。
6. 缺少能力时确认需求并导出开发任务包；不会自动下载或执行 AI 生成的代码。

观察默认关闭，重启不恢复。只记录选定元数据，不采标题、正文、按键、剪贴板内容、截图或命令行。
本地上限：120 分钟、4096 事件、128 应用、12 次记录、7 天；支持删除本次或清空。
退出观察仅覆盖本次核验的新进程，最多 128 个并发等待；暂停前已有进程不补跟踪。
窗口观察只记录显示/隐藏、状态与近似左右半屏/中央布局类别变化，初始状态作为基线，不保存精确坐标或显示器标识；窗口隐藏不代表进程退出或手工关闭。

新增规则可选择系统事件、前台应用、程序窗口出现，并组合窗口整理、打开目录/网页等动作。
窗口整理是一次性命令，包括左右半屏、居中、置顶/取消置顶；不会持续固定或自动恢复旧状态。
多窗口、未保存内容、DPI 和硬件行为请先用测试应用验收；CI 通过不能替代你的真实桌面验证。

核对构建：BUILD-INFO.json 中的 sourceCommit 应与下载页面的源码提交一致。
分发旁的 SHA256SUMS.txt 可核对便携 ZIP、安装 EXE 和来源说明；预览包尚未签名。

常用场景：自动化列表 → 从常用场景开始 → 选择场景 → 打开暂停草稿 → 填写程序/目录/快捷键 → 审阅并保存 → 明确启用。模板不会自动运行或替你猜测目标。

定期提醒：常用场景选择“定期打开提醒页”，填写自己的网址和分钟间隔。首次等待完整间隔；暂停、重启或检测重连后重新计时。每次打开可能产生新标签页；不会唤醒电脑，不是每天固定钟点。

固定钟点：自动化的“从常用场景开始”可选工作日打开目录；或选择时间检测，设置小时、分钟和多个星期日期。先填实际目标、保存审阅再启用。按Windows当前本地时区，只等待未来时刻，不补发睡眠/暂停时错过的任务，不唤醒电脑；夏令时缺失时刻跳过，重复时刻只取第一次，不识别节假日。UI退出后规则继续运行。

单次日期：选择“指定日期打开会议页面”，填写年月日、小时分钟和会议网址；只请求打开网页，不自动加入会议。过期或错过不补发，到期并交给规则不等于动作成功，请查看活动；规则保留供暂停或删除。电脑睡眠不唤醒，UI退出仍由后台等待。

锁屏静音：选择对应模板，审阅后启用。只对当时默认播放设备静音一次，解锁不会自动取消静音；不改音量、不改麦克风，暂停不会恢复。其他规则可选择设音量或取消静音，取消静音可能立即发声，请先核对较低音量。

麦克风快捷键：选择模板后填写全局快捷键，审阅并启用。只静音当时的默认通信麦克风一次，不改输入音量、不自动取消静音；会议应用可能选择其他输入设备，请在应用内核对。不是硬件隐私开关，不能保证所有麦克风停止收音。

PDF文件到达：选择“文件夹出现PDF后打开工具”，填写本机目录和程序后审阅启用。只监听新建/重命名，已有文件不补发，不包含子目录；一秒内多个文件可以合并。文件出现不等于下载完成，可给动作加延迟；不会读取文件内容或传递文件名。目录由用户手工填写，不接受AI导入路径。

AI候选需要目录、网址或显示器时，可把对应字段留空；导入确认会列出待填写项，进入暂停草稿后由你手工选择。未补齐不能保存或启用；AI提供的非空路径、网址和设备标识仍会被拒绝。

桌面提醒：常用场景选择“定期显示桌面提醒”，填写标题和内容，审阅保存后启用；也可组合指定日期或系统事件。默认不请求提示音，点击不打开链接。Windows勿扰、锁屏或通知设置可能隐藏提醒；活动成功只表示系统接受请求，不代表显示或已读，不适合紧急告警。暂停不能保证撤回已显示通知，临时图标约十秒内清理。

本机文档：选择“工作日定时打开计划文档”，手工填写完整路径、时刻和星期，审阅后启用。支持PDF、文本、无宏Office扩展名、开放文档和常见图片格式，具体名单见字段提示；交给Windows默认关联应用打开，不读取内容、不传参数，不保证载入完成。暂停不关闭文档。脚本/程序/快捷方式/含宏Office扩展名、网络共享及映射网络驱动器不支持；请使用可信文档。

工作时段提醒：选择“仅工作时段定期提醒”，填写正文后审阅启用。默认工作日9–18点每30分钟，从9:30开始，结束时刻不包含；10:10启用等10:30，错过不补发。可跨午夜，星期指时段开始那天。不识别节假日、不唤醒电脑；仅限制这个定时检测，若动作设置延迟仍可能在时段外执行。
