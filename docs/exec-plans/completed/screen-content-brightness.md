# 画面明亮面积检测

2026-10-17启动，2026-10-18本机与发布交付完成。一个实现代理，负责人文档/针对性审查/验收/Git。

用户可配置主屏画面大面积明亮时降低亮度，画面变暗或离开生效时段后按既有亮度租约恢复；可只在晚上采集，UI退出继续工作。检测浅色而非仅纯白，不把画面明亮程度当显示器背光或环境照度。

## 先确认的最小边界

- 先用framework-dependent本机夹具证明捕获/统计能运行并作短成本诊断，再接通真实能力，不先搭平台。
- 最终采用DXGI无边框路径，GPU64×36网格归约、CPU只回读4字节，最多每秒一次统计。原型源码已核对并取得约1fps统计，最终成本/释放见下方有效测量；先前错误标作DXGI的WGC读数已撤回。WGC因长期系统边框不进入正式实现。必要有限等待例外见 [ADR0011](../../adr/0011-screen-content-brightness.md)。避免CPU整屏读取、编码、保留或发送画面。
- 自动检测HDR，开启/未知时停采，关闭后事件恢复；用户无需判断或指定HDR状态。系统捕获提示边框、API支持、保护内容和失效保持明确说明，不把失败黑画面当正常暗场。
- 参数为明亮面积进入/退出阈值、稳定时长、可选HH:mm时段。时段外真正释放采集，最近边界唤醒；锁屏/屏幕关/暂停/无依赖释放，恢复重建基线。
- 复用通用声明UI、Engine与普通/硬件亮度恢复动作；不修改原亮度租约语义，不做逐帧DDC写入或新显示器身份框架。
