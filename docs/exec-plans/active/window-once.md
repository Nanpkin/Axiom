# 时段内成功执行一次与有限失败重试

2026-10-16，所有者本轮需求。用户新增能配置每天06:00–18:00内执行一次：08:00开机仍可执行，成功后本时段不重复；明确失败后按折叠配置的间隔及次数有限重试。

## 行为与操作验收

- 通用检测选择新增“在指定时段内执行一次”，默认每天06:00–18:00，支持星期及跨午夜，包含开始、不包含结束；跨午夜归属开始日期。旧精准钟点与定期检测保持原行为，不改旧配置。
- 选择动作、保存暂停草稿、启用；在时段内新启用或后台启动可立即执行，时段外等待下一有效开始，完全错过的旧时段不补。成功记录按规则和归属日期持久保留，重启/暂停/编辑不清空已完成事实。
- “失败重试”折叠项包含间隔分钟（默认5）及最多重试次数（默认3，不含首次；0关闭）。只对明确失败按单次deadline重试，成功、次数耗尽或时段结束停止；不在成功后周期检查。部分失败重试会重新执行整个动作，需在行为文案解释。
- 真正发出动作前原子登记在途；结果未知、通信中断、崩溃或结果未落盘不冒充失败后盲重发。Claim不是成功，活动分别解释等待、已成功、明确失败、次数耗尽与未确认。
- 不新增任意脚本或UI专用分支，UI退出后台继续。用户配置原地沿用，不备份；实机验收用合成配置/独立临时数据，避免改变已有规则。
