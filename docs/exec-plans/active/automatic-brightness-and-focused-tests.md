# 普通亮度自动选择与相关测试范围

2026-10-15，所有者本轮要求。用户新增能用普通亮度入口调整当前电脑的屏幕，不必辨认WMI与DDC/CI接口；现有硬件入口继续可用。开发验证只覆盖本轮亮度功能及直接边界。

## 范围

- 本机只读核查：内屏Brightness/Methods类明确NotSupported，连接查询成功；这不是内屏读数未知或权限失败。原普通入口仅内屏，导致本机不可用。
- 保留旧普通绝对/相对/恢复ID与参数，明确改为自动选择：优先支持内屏；仅接口确定缺失或明确无内屏目标时，使用现有主屏硬件路径。未知、权限、已有内屏写入/读回失败不回退。
- 沿用原全局亮度准入，避免嵌套取得同一租约；恢复只在初次捕获选择后端，后续固定本轮目标、范围与基线，结束仍按原守卫恢复。硬件显式主屏/全部入口不改变。
- 名称、说明及直接相关模板同步表达实际范围，不新建硬件可用性平台。
- 持久化“最多相关功能测试”要求；CI也不能默认全套或机械重复相同来源的功能检查，保留构建、来源及文件校验。
