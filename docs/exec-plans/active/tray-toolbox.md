# 任务栏托盘管理

2026-10-16，执行中。一个实现代理；负责人只做针对性审查、验收、文档与Git。

用户能在工具箱多选完整程序路径，选择“仅Axiom启动时隐藏”或“持续隐藏”，直接启停并查看真实执行结果，无需拼自动化规则。UI退出后按已保存模式工作。

## 范围与未决项

- 复用当前托盘选择面板、Host授权/Engine仲裁和Agent删除动作；普通tray.hide仍是一次命令，不自动迁移已有用户规则。
- 工具内部配置不混入普通规则列表，不允许通用保存/删除误改；保存有版本校验，关闭保留名单并取消后续工作。
- 持续模式按需系统通知，处理图标重新创建及Explorer重建；无周期扫描。事件合并，重新核对完整路径/当前图标身份，避免删除反馈形成空转。
- 关闭不承诺还原已删除图标；菜单/气泡通知及系统记录识别限制明确展示。未识别/未确认不得报成功。
- 已定方案：稳定工具内部任务为唯一状态；持续模式使用Agent只读目标观察，经Host生命周期输入驱动Engine命令。TaskbarCreated重绑Explorer hook，稳定父键通知覆盖托盘记录重建；无全桌面hook。待验证同身份重建、事件合并与取消，不铺平台。

## 相关验收与交付

- 仅工具配置/生命周期/协议和直接受影响的托盘事件边界测试，执行前更新change-test-suites；不重复时间、亮度或全UI回归。
- 真实UI验收本轮入口、模式、多选与取消；实际删除用合成托盘图标，不操作用户其他软件图标。
- 通过后commit/push、准确CI与批次Release；正常停止并更新固定本机预览，核对原配置、路径、版本与后台连接。
- 验收证据待填；未验收不记通过。
