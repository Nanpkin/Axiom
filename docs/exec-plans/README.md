# 执行计划索引

当前任务只看 [当前交接](../product/current-state.md)。小改动和文档维护不建计划；确需跟踪跨层未决项时才创建短计划。

- [已完成](completed/README.md)：当时任务范围与验收证据，非当前待办或整项产品通过证明。
- [活动目录](active/README.md)：只有当前交接明确指向的计划才属于正在执行的任务。
- [归档](archived/README.md)：停止沿用且未全项验收的历史，不能记成完成。

旧编号、阶段“下一步”与既有active文件不自动授予继续开发；有效contract/ADR仍保留。完成时只更新本次计划和短交接，不向旧计划追加新流水账。
