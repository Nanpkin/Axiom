# 使用观察与建议闭环

2026-10-09 首版。入口是工作台“使用观察”。仅用户显式开启，选择前台应用切换、程序启动、1–120 分钟、排除 exe 名单和目的。重启不恢复；UI 持有 Host 管道租约，关闭/崩溃断开即停止，规则不受影响。任何页面底部都有状态和结束按钮；到期使用一次 deadline，界面读取有时间戳、不周期刷新。

Agent 通过前台 WinEvent 和已有共享 Win32_ProcessStartTrace 收集元数据，当前用户与会话核验后发送路径；没有窗口标题、命令行、正文或键鼠采集。独立消费者释放不会影响规则。首版尚无退出、窗口布局、锁屏、电源或设备观察。调用现有命令 Provider 时额外写 Axiom 动作来源标记；其他事件来源未知，不把窗口变化当手动操作。不尝试从切换推断全部工作流程。

Host `UsageObservationController` 管理生命周期、身份受权后的请求、聚合和存储。`UsageRecorder` 为对象分配局部随机别名，合并重复前台事件，最多 4096 事件、128 对象且路径字典 12000 字符；达到上限停止并说明缺口。Agent 两级队列各有容量，溢出停止采集，Host 标记间断，不重连补造历史。未知进程或权限不足作为缺口。暂停后继续保持原绝对截止时间。

`usage.db` 最多 12 次、7 天；仅在操作时清理过期记录，无清理轮询。无备份/EFS。SQLite secure_delete，主动删除使用 VACUUM；不承诺存储硬件的取证级擦除。重启将未结束记录标为已停止，并记中断。记录每页 64 条，通过 Host 读取；路径字典只留本机。反馈随对应记录删除。

本地分析当前有两种：至少三次、30 秒内相继启动的程序可进入“确认意图 → 默认暂停的规则编辑器”；两分钟内反复前台切换只标证据不足。显示次数、机会总数和限制；Axiom 动作与缺口切断模式序列，未知来源不当手动劳动，不宣称因果或节省时间。接受不保存、不启用；编辑、保存、启用仍走现有参数/权限/资源检查。检测按文件名，启动按完整路径，已运行跳过，结束不自动关闭，用户审阅时明确说明。

摘要 JSON v1 使用真实运行时能力目录（资源选择值不导出）、匿名对象、统计、少量相对时间证据及不确定性。64 KiB 上限；路径映射、排除名单、标题和完整流水不导出。目的为用户提供文本，在可编辑预览中可删减。只有用户点击复制才进入剪贴板，没有网络上传、API Key 或模型调用。

导入最多 64 KiB、深度 16；拒绝未知字段、重复字段、错误版本/观察 ID/能力/组合/参数/对象。执行字段中的对象只能用本次已知别名；拒绝自由文本执行参数、路径、URL 和命令行。解释文本仅展示，不执行。导入 existing 进入暂停草稿；extension 经确认生成结构化源码开发任务；insufficient 仅说明缺少证据。导出任务默认不含观察、映射或个人机器信息，用户需求文本仍须预览删减。

## 最短体验和 Windows 待验

1. 创建程序运行或快捷键检测，动作选“整理窗口状态”，多选测试程序，保存并触发；查看结果，暂停取消等待，退出 UI 后规则仍可触发。
2. 使用观察，5 分钟，两项范围，排除一个测试应用；启动/切换其他测试程序，暂停/继续，查看记录；被排除程序不出现，标题/参数无字段。
3. 使用临时合成程序各重复启动三次（不是伪装成用户真实记录的内置样本），审阅配套启动建议；取消不保存，接受进入暂停草稿，调整后保存。
4. 预览并删减摘要，复制给自己选择的 AI；导入结构化返回，核对对象、限制及默认暂停；缺失能力生成任务包。无需 API Key。
5. 关闭 UI、到期、Host/Agent 中断，确认记录停止、缺口可见、自动化规则仍正常；重新打开不恢复。逐条/清空删除后重开不再出现。

Linux 验证纯逻辑、存储、脱敏、导入与协议；Windows CI 构建不能替代以上真实桌面检查。
