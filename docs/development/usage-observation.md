# 使用观察与建议闭环

2026-10-09 首版。入口是工作台“使用观察”。仅用户显式开启，选择前台应用切换、程序启动、系统会话/供电/网络可用性事件、1–120 分钟、排除 exe 名单和目的。重启不恢复；UI 持有 Host 管道租约，关闭/崩溃断开即停止，规则不受影响。任何页面底部都有状态和结束按钮；到期使用一次 deadline；正常停止、到期、容量或采集失败通过租约管道主动通知 UI。界面读取有时间戳、不周期刷新。

Agent 通过前台 WinEvent 和已有共享 Win32_ProcessStartTrace 收集元数据，当前用户与会话核验后发送路径；没有窗口标题、命令行、正文或键鼠采集。独立消费者释放不会影响规则。新增 WTS 锁屏/解锁、WM_POWERBROADCAST 恢复与供电变化、NetworkChange 网络可用性（不含地址/SSID），和规则共享隐藏窗口订阅；尚无进程退出、窗口布局、音频/显示器/USB 观察。调用现有命令 Provider 和 HDR 适配器时额外写 Axiom 动作发起标记，能核对的程序目标保留本地引用；本次被 Axiom 操作过的对象不参与本地重复模式，避免把已自动完成的工作再建议一次。其他事件来源未知，不把窗口变化当手动操作。不尝试从切换推断全部工作流程。

Host `UsageObservationController` 管理生命周期、身份受权后的请求、聚合和存储。`UsageRecorder` 为对象分配局部随机别名，合并跨其他事件的连续前台停留，并在切换、暂停、排除或停止时结束停留时间；停留不代表用户实际操作时间。最多 4096 事件、128 对象且路径字典 12000 字符；达到上限停止并说明缺口。Agent 两级队列各有容量，溢出停止采集，Host 标记间断，不重连补造历史。未知进程或权限不足作为缺口。暂停后继续保持原绝对截止时间。

`usage.db` 最多 12 次、7 天；仅在操作时清理过期记录，无清理轮询。无备份/EFS。SQLite secure_delete，主动删除使用 VACUUM；不承诺存储硬件的取证级擦除。重启将未结束记录标为已停止，并记中断。记录每页 64 条，通过 Host 读取；路径字典只留本机。反馈使用不导出的本地对象键，在保留记录间减少同类重复建议；随对应记录删除。

本地分析当前有三种：至少三次在解锁、恢复、供电或网络可用事件后一分钟内启动同一程序的候选（每个机会同一目标只计一次）；至少三次、30 秒内相继启动的程序可进入“确认意图 → 默认暂停的规则编辑器”；两分钟内反复前台切换只标证据不足。显示次数、机会总数、最多三条相对时间证据片段和限制；Axiom 动作与缺口切断模式序列，未知来源不当手动劳动，不宣称因果或节省时间。接受不保存、不启用；编辑、保存、启用仍走现有参数/权限/资源检查。检测按文件名，启动按完整路径，已运行跳过，结束不自动关闭，用户审阅时明确说明。

摘要 JSON v1 使用真实运行时能力目录（资源选择值不导出）、匿名对象、统计、少量相对时间证据及不确定性。工作台还可独立导出同一注册的机器可读 JSON 和可读开发目录。64 KiB 上限；路径映射、排除名单、标题和完整流水不导出。目的为用户提供文本，在可编辑预览中可删减。只有用户点击复制才进入剪贴板，没有网络上传、API Key 或模型调用。

导入最多 64 KiB、深度 16；拒绝未知字段、重复字段、错误版本/观察 ID/能力/组合/参数/对象。执行字段中的对象只能用本次已知别名；拒绝自由文本执行参数、路径、URL 和命令行。解释文本仅展示，不执行。导入 existing 进入暂停草稿；extension 经确认生成结构化源码开发任务；insufficient 仅说明缺少证据。导出任务默认不含观察、映射或个人机器信息，用户需求文本仍须预览删减。

## 最短体验和 Windows 待验

1. 创建程序运行或快捷键检测，动作选“整理窗口状态”，多选测试程序，保存并触发；查看结果，暂停取消等待，退出 UI 后规则仍可触发。
2. 使用观察，5 分钟，两项范围，排除一个测试应用；启动/切换其他测试程序，暂停/继续，查看记录；被排除程序不出现，标题/参数无字段。
3. 使用临时合成程序各重复启动三次（不是伪装成用户真实记录的内置样本），审阅配套启动建议；取消不保存，接受进入暂停草稿，调整后保存。
4. 预览并删减摘要，复制给自己选择的 AI；导入结构化返回，核对对象、限制及默认暂停；缺失能力生成任务包。无需 API Key。
5. 关闭 UI、到期、Host/Agent 中断，确认记录停止、缺口可见、自动化规则仍正常；重新打开不恢复。逐条/清空删除后重开不再出现。

Linux 验证纯逻辑、存储、脱敏、导入与协议；Windows CI 构建不能替代以上真实桌面检查。

系统事件检测可与程序/窗口/托盘动作组合，例如解锁后启动配套程序、恢复后最大化工作窗口。首次订阅不补发锁屏或供电状态，不把未知当离线；不提供锁屏键盘发送组合。原生事件、现代待机、硬件供电切换需 Windows 实测。

新增 `target.open`：程序/启动/快捷键/系统事件可请求打开一个本机目录或 http/https 网页。拒绝脚本、自定义协议、URL 账号密码和 UNC；不自动关闭窗口。系统接受请求不代表页面加载完成。该自由文本目标不从模型导入，需用户在编辑器中填写。网络可用性变化指接口可用，不作互联网连通性承诺。

摘要上限包含分析提示词；超过预算时优先保留次数最高的 6 个模式、3 条代表事件并省略能力说明，保留完整参数类型/范围/选项/组合，明确列出省略项。可读与机器目录均来自同一次真实注册。

窗口整理新增当前显示器左半屏、右半屏和中央 80% 布局：按显示器工作区计算，在原生调用期间临时设置线程 DPI 上下文并及时还原；不修改全局显示配置。最小化/最大化窗口先还原，位置和大小读回后才确认成功；之后手动调整不受干预。多 DPI/多显示器实机场景仍待验。

新增“程序成为前台”检测：多选程序名，切入任意目标成立，目标组内互相切换不重复触发；离开或身份未知取消等待。仅事件唤醒时读当前前台，避免把延迟队列中的历史窗口当当前状态。与观察共用一个有界 WinEvent 源；观察保存通知时间，规则使用当前核验状态。不提供此前台检测与键盘发送的组合。暂停/继续后的进程事件按实际订阅起点过滤，不把暂停期间延迟送达的旧通知记入新时段。

## 按窗口出现触发

“程序窗口出现”检测支持多选程序名；可直接组合整理窗口状态、打开目录/网页、程序和托盘动作。初始已有窗口不补执行，同一目标仍有其他可见主窗口时不重复触发；所有目标主窗口隐藏或销毁才结束条件。最小化窗口仍算可见，拥有者弹窗不算主窗口，不读取标题。窗口消失不表示程序退出或手动关闭。

实现按需共享现有 WinEvent 源，仅订阅主窗口生命周期通知；一次初始枚举后按通知更新有界窗口集合。核验失败记未知，不当不存在；队列或集合溢出明确失败。手动验收：创建“程序窗口出现 → 右半屏整理”，打开新目标窗口、隐藏至托盘再显示、保留第二个主窗口、暂停规则；检查单次触发和取消，UI 退出后规则继续。

## 观察目的与未记录前台

“补充本次目的”允许观察中或结束后写下刚才在做什么，最多 500 字，也可清空。说明本地保存，进入导出预览，不修改事件、不重开观察；请在预览中删掉不希望分享的文字。切到 Axiom 自身或用户范围外的前台时只记不带对象的边界，结束前一应用停留并中断分析序列，不采集被排除对象。
