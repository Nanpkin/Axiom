# 使用观察与建议闭环

2026-10-09 首版。入口是工作台“使用观察”。仅用户显式开启，选择前台应用切换、程序启动、本次新进程退出、窗口显示/隐藏/状态、系统会话/供电/网络可用性事件、1–120 分钟、排除 exe 名单和目的。重启不恢复；UI 持有 Host 管道租约，关闭/崩溃断开即停止，规则不受影响。任何页面底部都有状态和结束按钮；到期使用一次 deadline；正常停止、到期、容量或采集失败通过租约管道主动通知 UI。界面读取有时间戳、不周期刷新。

Agent 通过前台 WinEvent 和已有共享 Win32_ProcessStartTrace 收集元数据，当前用户与会话核验后发送路径；没有窗口标题、命令行、正文或键鼠采集。独立消费者释放不会影响规则。新增 WTS 锁屏/解锁、WM_POWERBROADCAST 恢复与供电变化、NetworkChange 网络可用性（不含地址/SSID），和规则共享隐藏窗口订阅；默认音频、显示模式和USB类别的后续范围与限制见下文；尚无任意坐标/尺寸或特定设备身份观察。调用现有命令 Provider 和 HDR 适配器时额外写 Axiom 动作发起标记，能核对的程序目标保留本地引用；本次被 Axiom 操作过的对象不参与本地重复模式，避免把已自动完成的工作再建议一次。其他事件来源未知，不把窗口变化当手动操作。不尝试从切换推断全部工作流程。

Host `UsageObservationController` 管理生命周期、身份受权后的请求、聚合和存储。`UsageRecorder` 为对象分配局部随机别名，合并跨其他事件的连续前台停留，并在切换、暂停、排除或停止时结束停留时间；停留不代表用户实际操作时间。最多 4096 事件、128 对象且路径字典 12000 字符；达到上限停止并说明缺口。Agent 两级队列各有容量，溢出停止采集，Host 标记间断，不重连补造历史。未知进程或权限不足作为缺口。暂停后继续保持原绝对截止时间。

`usage.db` 最多 12 次、7 天；仅在操作时清理过期记录，无清理轮询。无备份/EFS。SQLite secure_delete，主动删除使用 VACUUM；不承诺存储硬件的取证级擦除。重启将未结束记录标为已停止，并记中断。记录每页 64 条，通过 Host 读取；路径字典只留本机。反馈使用不导出的本地对象键，在保留记录间减少同类重复建议；随对应记录删除。

本地分析当前有三种：至少三次在解锁、恢复、供电或网络可用事件后一分钟内启动同一程序的候选（每个机会同一目标只计一次）；至少三次、30 秒内相继启动的程序可进入“确认意图 → 默认暂停的规则编辑器”；两分钟内反复前台切换只标证据不足。显示次数、机会总数、最多三条相对时间证据片段和限制；Axiom 动作与缺口切断模式序列，未知来源不当手动劳动，不宣称因果或节省时间。接受不保存、不启用；编辑、保存、启用仍走现有参数/权限/资源检查。检测按文件名，启动按完整路径，已运行跳过，结束不自动关闭，用户审阅时明确说明。

摘要 JSON v1 使用真实运行时能力目录（资源选择值不导出）、匿名对象、统计、少量相对时间证据及不确定性。工作台还可独立导出同一注册的机器可读 JSON 和可读开发目录。64 KiB 上限；路径映射、排除名单、标题和完整流水不导出。目的为用户提供文本，在可编辑预览中可删减。只有用户点击复制才进入剪贴板，没有网络上传、API Key 或模型调用。

导入最多 64 KiB、深度 16；拒绝未知字段、重复字段、错误版本/观察 ID/能力/组合/参数/对象。执行字段中的对象只能用本次已知别名；拒绝自由文本执行参数、路径、URL 和命令行。解释文本仅展示，不执行。导入 existing 进入暂停草稿；extension 经确认生成结构化源码开发任务；insufficient 仅说明缺少证据。导出任务默认不含观察、映射或个人机器信息，用户需求文本仍须预览删减。

## 最短体验和 Windows 待验

1. 创建程序运行或快捷键检测，动作选“整理窗口状态”，多选测试程序，保存并触发；查看结果，暂停取消等待，退出 UI 后规则仍可触发。
2. 使用观察，5 分钟，两项范围，排除一个测试应用；启动/切换其他测试程序，暂停/继续，查看记录；被排除程序不出现，标题/参数无字段。
3. 使用临时合成程序各重复启动三次（不是伪装成用户真实记录的内置样本），审阅配套启动建议；取消不保存，接受进入暂停草稿，调整后保存。
4. 预览并删减摘要，复制给自己选择的 AI；导入结构化返回，核对对象、限制及默认暂停；缺失能力生成任务包。无需 API Key。
5. 关闭 UI、到期、Host/Agent 中断，确认记录停止、缺口可见、自动化规则仍正常；重新打开不恢复。逐条/清空删除后重开不再出现。

Linux 验证纯逻辑、存储、脱敏、导入与协议；Windows CI 构建不能替代以上真实桌面检查。

系统事件检测可与程序/窗口/托盘动作组合，例如解锁后启动配套程序、恢复后最大化工作窗口。首次订阅不补发锁屏或供电状态，不把未知当离线；不提供锁屏键盘发送组合。原生事件、现代待机、硬件供电切换需 Windows 实测。

新增 `target.open`：程序/启动/快捷键/系统事件可请求打开一个本机目录或 http/https 网页。拒绝脚本、自定义协议、URL 账号密码和 UNC；不自动关闭窗口。系统接受请求不代表页面加载完成。该自由文本目标不从模型导入，需用户在编辑器中填写。网络可用性变化指接口可用，不作互联网连通性承诺。

摘要上限包含分析提示词；超过预算时优先保留次数最高的 6 个模式、3 条代表事件并省略能力说明，保留完整参数类型/范围/选项/组合，明确列出省略项。可读与机器目录均来自同一次真实注册。

窗口整理新增当前显示器左半屏、右半屏和中央 80% 布局：按显示器工作区计算，在原生调用期间临时设置线程 DPI 上下文并及时还原；不修改全局显示配置。最小化/最大化窗口先还原，位置和大小读回后才确认成功；之后手动调整不受干预。多 DPI/多显示器实机场景仍待验。

新增“程序成为前台”检测：多选程序名，切入任意目标成立，目标组内互相切换不重复触发；离开或身份未知取消等待。仅事件唤醒时读当前前台，避免把延迟队列中的历史窗口当当前状态。与观察共用一个有界 WinEvent 源；观察保存通知时间，规则使用当前核验状态。不提供此前台检测与键盘发送的组合。暂停/继续后的进程事件按实际订阅起点过滤，不把暂停期间延迟送达的旧通知记入新时段。

## 按窗口出现触发

“程序窗口出现”检测支持多选程序名；可直接组合整理窗口状态、打开目录/网页、程序和托盘动作。初始已有窗口不补执行，同一目标仍有其他可见主窗口时不重复触发；所有目标主窗口隐藏或销毁才结束条件。最小化窗口仍算可见，拥有者弹窗不算主窗口，不读取标题。窗口消失不表示程序退出或手动关闭。

实现按需共享现有 WinEvent 源，仅订阅主窗口生命周期通知；一次初始枚举后按通知更新有界窗口集合。核验失败记未知，不当不存在；队列或集合溢出明确失败。手动验收：创建“程序窗口出现 → 右半屏整理”，打开新目标窗口、隐藏至托盘再显示、保留第二个主窗口、暂停规则；检查单次触发和取消，UI 退出后规则继续。

## 观察目的与未记录前台

“补充本次目的”允许观察中或结束后写下刚才在做什么，最多 500 字，也可清空。说明本地保存，进入导出预览，不修改事件、不重开观察；请在预览中删掉不希望分享的文字。切到 Axiom 自身或用户范围外的前台时只记不带对象的边界，结束前一应用停留并中断分析序列，不采集被排除对象。

## 本次新进程退出与收尾建议

开始观察时可另选“本次新进程退出”，默认关闭。共享现有进程启动通知，只为本次核验过的进程等待真实退出句柄（最多 128 个并发），使用 OS 退出时间；暂停/结束释放句柄。恢复后不会补跟踪已运行进程，无全量进程扫描或轮询。极短进程、权限或容量不足会留下缺口；不记录退出码或推断手动关闭。排除程序不会建立退出跟踪。

至少三次在 30 秒内相继退出两个程序可形成收尾候选；展示次数、已观察机会、代表片段和覆盖限制。Axiom 动作目标或缺口打断的序列排除。确认后生成“程序全部退出 → 正常关闭配套程序最近启动的一个实例”的暂停草稿；不强杀、不自动重开，用户仍须保存并启用。多实例退出次数不等于规则触发次数，未保存内容可能要求应用确认。

人工验收：勾选退出、启动两个合成测试应用后按顺序正常关闭，核对两条退出；重复三次审阅草稿但不启用；再测试排除、暂停前已启动进程、容量上限和短进程缺口。记录与任务包不得使用真实私人数据作为提交附件。

窗口整理还支持一次性置顶/取消置顶：保持大小、位置和可见性，不激活窗口；按实际置顶标记确认结果，不维持持续控制或条件结束恢复。原生回归验证两次反向操作与之后手动最小化。

## 窗口状态观察与整理建议

开始时可单独选择窗口状态，默认关闭。观察顶层无拥有者的可见主窗口；初始窗口只作基线，随后显示、隐藏/销毁、最小化、最大化、还原或近似布局类别变化才记录。记录不含标题、窗口句柄或位置坐标。共享窗口事件源，一次初始枚举后增量更新；移动/调整大小但类别未变时不重复核验进程元数据，缓存上限 4096 个窗口。排除应用和 Axiom 自身不进入记录，核验失败或过载报告缺口。

同一应用至少三次“显示后 30 秒内最小化/最大化”可提供暂停的“程序窗口出现 → 整理窗口状态”草稿。应用可能自己改变窗口，不能当作用户手工重复；多窗口时不能确认同一窗口，也不会逐个整理后续窗口。卡片明确要求审阅目标与可选标题筛选，一次操作不恢复。已标记 Axiom 动作的对象和缺口序列不用于建议。

人工验收：仅开启窗口范围，启动合成测试应用，显示、最大化、最小化、还原、隐藏，核对各条记录；已有状态不能伪装新操作；关闭观察后既有窗口规则仍继续。再重复三次显示/调整，审阅暂停草稿；不在真实未保存内容上启用验收规则。

近似布局分类：瞬时读取窗口和当前显示器工作区，在匹配左右半屏或中央 80% 时只记录 left/right/center 类别，允许按 DPI 缩放的窗口边框误差。精确坐标、显示器标识和尺寸不会写入记录或摘要；任意摆放归为普通位置。显示后重复摆放可进入同一暂停草稿流程，动作使用触发时的显示器，不保证复原观察时的显示环境。负坐标/奇数宽度/边框容差有纯逻辑回归，原生测试验证三种真实布局的观察通知；多屏/混合 DPI 仍待人工验收。

### 低电量通知验收

系统事件范围包含电量从高于20%或10%降至该阈值及以下。只保存事件类别，无电池标识/百分比流水。首次或未知读数后重新建立基线，不补事件；上升不触发，回升超过阈值后再次下降才触发。一次大幅下降可能同时跨两个阈值；这是两个不同检测选项。来源是系统综合电量，不推断正在用电池或每块电池状态。

在有电池的Windows桌面，选择系统事件检测和所需阈值，配置启动一个测试工具，保存启用后关闭UI；实际放电穿越时核对活动与工具启动，重复低位读数不重复动作，暂停后不执行。重新开启观察并选择系统范围，核对记录中相同阈值事件与匿名摘要。启动时已经低于阈值不应补执行。CI仅以合成电量消息验证原生注册/消息/共享释放，以纯逻辑覆盖边界，不代替真实电池变化。

窗口收尾候选需要同时选择窗口范围与本次新进程退出：同一应用窗口消失后30秒内另一个程序退出至少三次，保留次数、窗口消失机会、代表时间片段。重新显示或缺口会中断，已知Axiom动作目标不参与。单个窗口的消失不证明应用所有窗口消失；候选明确此差异，确认后才打开 `window.absent → program.close` 暂停草稿，正常关闭最新实例、不自动重开、不强杀。

### 显示环境类别与布局证据

系统范围接收 `WM_DISPLAYCHANGE`，只保存显示模式变化类别，不保存分辨率/色深载荷或显示器标识；不保证每次插拔都会产生该通知。窗口范围同时开启时，至少三次显示变化后一分钟内同应用出现近似左/右半屏或中央布局，可提出显示事件→一次窗口状态动作的暂停草稿。同一显示事件每个应用最多计一次，其他系统边界/缺口/Axiom动作中断；不能认定是手工调整，不能识别特定屏幕组合，也不复原旧坐标。

真实验收：在临时规则中选显示分辨率/色深变化与窗口状态动作，安全地改变桌面显示模式，核对活动和目标窗口；先结束规则再恢复用户显示设置。观察中核对只有类别而无具体显示参数。CI仅向自身临时消息窗口投递合成通知，并用合成序列验证证据草稿，不改变CI或用户显示配置。

### USB类别范围

系统范围包括任意USB接口类别的接入/移除通知，使用 `RegisterDeviceNotificationW` 按USB类别订阅。只读取通知头中的类别，不读取设备路径、序列号或完整设备清单；最后消费者退出时注销。复合设备/系统重枚举可产生多次，不把通知次数等同物理插拔次数，当前不能按具体设备筛选。重复接入通知后启动程序可进入原有证据/暂停草稿链，明确任意USB范围。

真实验收：用测试USB设备接入/移除，核对选中系统范围时只出现类别记录，停止后不记录；创建任意USB接入→启动测试工具的规则，检查UI关闭仍工作与暂停后的取消。CI仅给自身隐藏窗口发送合成类别通知，不改变真实设备。

### 默认音频范围

默认关闭，单独选择默认播放设备/默认通信麦克风变化。通过共享 `IMMNotificationClient` 接收常规播放角色与通信录音角色的变化通知，不枚举设备、不解引用设备标识指针、不录音；移除默认设备也可能通知，不保证应用自行选择的路由发生变化。此范围的来源未知，重复事件后启动可进入带角色限制的暂停草稿，不能选择某个具体设备。

规则侧音频通知不可用时只将音频资源置Unknown，保持其他Provider流；检查Windows音频服务后暂停并重新启用或重启后台。不轮询重试COM激活，原生启动/结束等待有界，关闭未完成时不会不断创建新线程。观察主动选了音频而无法启动时明确失败/缺口，可关闭该范围后重开其他观察。

真实验收：用Windows声音设置切换默认播放设备和默认通信麦克风，核对两个类别分开、其他角色变化不冒充；单独应用内改路由不应被宣称已检测。开启音频规则后关闭UI检查活动与动作，再暂停；观察关闭后释放自身租约而规则仍能接收。CI验证COM通知注册/共享/释放、合成回调角色过滤和不可用源隔离，不操作真实默认设备或音量。

### 播放音量动作验收

规则可在锁屏等事件后对执行开始时的默认播放设备设置一次主音量/静音/取消静音。所有此类操作共用同一规则资源；不选具体设备、不读标识、不操作麦克风或应用会话音量。设置音量不取消静音，静音操作不改音量；后续手动修改不被压制，暂停不恢复。

实机步骤：先核对较低音量；创建并审阅锁屏静音暂停草稿，启用后锁屏，检查活动读回及Windows声音设置；解锁不应自动取消静音。手动修改后保持不变直到下一次触发，关闭UI再验证规则，最后暂停。分别测试设音量不取消静音、静音不改百分比、默认设备缺失和设备切换；取消/超时报告可能已修改，不应有自动反向写回或无界重试。CI只验证纯逻辑/生命周期和构建，不冒充真实音量效果。

默认通信麦克风另有独立动作/资源，只静音或取消静音，不调输入增益、不持续控制、不自动恢复。实机请用Windows声音设置确认默认通信输入，再在目标会议应用核对实际选择的输入；用快捷键静音并检查系统状态/应用收音。换到非默认输入验证限制说明，暂停后不应反向取消静音。CI未用真实麦克风验证收音，不能宣称所有设备均已静音或提供硬件级隐私保护。

### 恢复建议与导出反馈

接受、忽略或标记不符合需求的模式仍以本地反馈键跨观察减少重复；“重新显示已处理建议”按当前完整记录的最多12个模式撤销相同键的反馈，保留无关反馈、记录和已有规则。生成草稿后未保存也可恢复，不需要清空全部观察。摘要的 `patterns` 只包含未处理模式，`handledPatterns` 用当前观察随机应用别名标明已处理模式；不会导出路径或本地反馈哈希。恢复只改变建议显示，不自动配置或执行规则。

### 返回工作环境后的窗口整理

本地布局模式也覆盖解锁、睡眠恢复、USB接入类别、默认播放/默认通信输入变化后一分钟内的首个同应用左右半屏/中央布局。按事件类别、目标应用和布局分别累计至少三次，不把不同触发凑为三次，也不把同一次机会内的左右调整算两次。来源未知；任意环境边界/缺口/已知Axiom来源中断序列，已知Axiom动作目标排除。建议复用实际事件检测和窗口动作，只生成暂停草稿。睡眠恢复未必已解锁，设备通知不代表具体设备，仍需用户确认意图与动作时机。

### 文件到达规则边界

文件到达是独立规则检测，不加入使用观察，不记录文件名或内容。仅监听指定本机目录的FileName创建/重命名通知，不递归、不枚举已有文件；PDF、Office、图片、压缩文件或所有文件按扩展名筛选。同目录共享通知，至多16种目录/类别组合，一秒内合并为每种组合一次。事件队列/系统缓冲溢出、目录或权限失败使文件检测Unknown，不影响其他能力，无扫描补漏或后台无限重试。

真实操作：创建暂停的PDF到达→配套程序规则，填写本机目录和程序，启用后放入PDF或把临时扩展名重命名为PDF；已有文件不补发，子目录不监听。同秒多文件允许合并，不保证每个文件动作一次，也不证明写入完成；按需延迟动作。移动目录后更新路径并重新启用，暂停释放监听，UI退出规则继续。UNC及映射网络驱动器不支持；此功能不传递文件名给动作、不打开/读取到达文件。跨平台测试用明确合成临时文件，实际下载程序流程仍须实机验收。

### 需要本机信息的待补全候选

AI可为必填Text/TextList/DirectoryPath/Resource字段给空字符串（或省略），生成未保存、默认暂停的待补全草稿；确认页列出字段标签。非空自由文本、目录/网址和设备标识仍拒绝，程序对象仍须使用本次观察的随机别名。其他必填字段、类型、范围、选项、能力/组合和已填调用仍验证；缺手工值只影响该调用的预览，不绕过正常保存/编译/Agent校验。

用户在现有编辑器补目录或网址，或选择真实HDR显示器后，才可能保存/启用。未补齐时即便保持暂停也不能保存为有效规则。摘要/机器能力目录提供fieldKinds数值图例，提示词说明留空边界；不向AI导出本机目录或设备选择。
