# 当前状态与交接

更新：2026-10-09。当前是持续变化的小型 Windows 11 x64 自动化工具，HDR 只是第一个场景。源码以此可用版本重新开始 Git 历史；个人现场记录和原始验收证据只留本机，不作为云端必读资料。

## 入口与架构

- 本机预览：artifacts/Axiom-preview/Axiom.exe；分发包：artifacts/release。源码仓库不包含二进制，按 [分发说明](../development/distribution.md) 构建。
- 根目录 Native AOT 启动器；app 中的 Host/Session Agent/WinUI 共用自带运行库。Host 是 Service 角色，尚未注册 Windows Service。UI 完全退出后后台继续工作。
- 用户数据在 USERPROFILE 下的 .axiom，配置通过 Host/SQLite 写入。开发与正式入口访问同一数据根；不自动备份、不启用 EFS，不播种或恢复某位开发者的规则。
- 同账户 UAC 提权，登录为当前用户最高权限交互任务；安装版当前用户安装，有开始菜单、可选桌面入口及系统卸载登记。卸载保留数据，只清本安装所属登录任务。
- 按 [代码定位表](../development/code-map.md) 阅读本轮相关代码，边界见 [架构地图](../../ARCHITECTURE.md)。旧计划不是执行指令。

## 已实现

| 场景 | 当前行为和限制 |
|---|---|
| 自动化 | 声明驱动检测/动作/参数；保存、编辑、暂停、删除；各规则独立异步等待，同资源保留仲裁；不支持任意条件组合和完整多步骤流程 |
| 程序检测 | 原生 Win32_ProcessStartTrace 共享事件源和精确退出等待，无窗口依赖、无周期枚举；未知不当退出，初始已运行进程不补触发；极短进程可能错过身份核验 |
| 启动检测 | 每次后台启动或本次开机首次；Windows BootId 持久化去重；打开 UI 不触发，新增首次规则不补执行，失败不自动重发 |
| HDR | 游戏开始按规则设置，结束按本轮基线恢复；手动修改、暂停或观察中断遵守接管边界；正在控制时拒绝停止后台 |
| 程序动作 | 启动支持参数、目录、延迟和实例策略；关闭支持正常/强制与多完整路径；隐式窗口隐藏不能强制阻止 GUI 自行显示 |
| 窗口动作 | 多完整路径、延迟、标题过滤、有界等待；按需 WinEvent，一次 WM_CLOSE 后确认隐藏/销毁，不强杀、不持续压制 |
| 托盘动作 | 当前可识别图标面板，多选、搜索、刷新；完整路径和 SID/会话核对后一次删除 ID/GUID 图标；未公开系统记录格式有版本限制，重建后可能再出现 |
| 组和工具箱 | 进程组批量输入、文件多选、组内勾选；Steam 工具按启动扫描元数据，缓存按通知失效，维护固定组/排除项，不递归扫描游戏目录；已保存规则不会自动跟随组 |
| 快捷键 | 设置中切换 Axiom 窗口；规则检测多组合、动作有序发送可重复组合及延迟；共用唯一 RegisterHotKey 消息线程，无轮询或键盘 hook；按键只发前台，拒绝自身监听组合循环 |
| 活动与主题 | 持久活动日志、按可视高度分页、清除七天前日志；主题默认跟随系统，可浅/深色切换；批量输入用应用内弹窗 |
| 扩展 | 内置 IAutomationPlugin / ISessionCapabilityProvider 注册扩展，通用 Engine/存储/IPC；无外部 DLL 热加载或市场，HDR 恢复适配器独立 |

## 本轮持续开发：观察、建议与能力扩展

已接通的用户路径：
- 自动化：窗口最小化/最大化/还原及当前屏幕左半屏/右半屏/居中、置顶/取消置顶；锁屏/解锁/恢复/供电/网络可用性事件；打开目录或 http/https 网页；多选前台应用检测和程序可见主窗口检测。声明驱动现有编辑器与 Engine，UI 退出规则继续。
- 主动观察：前台切换、程序启动、可选本次新进程退出、窗口状态/近似布局、会话/供电/网络事件及 Axiom 动作来源；1–120 分钟、排除应用、暂停/继续/结束、本地分页、删除/清空。UI 关闭即结束，重启不恢复。4096 事件、128 对象、12 次/7天；共享订阅独立释放。Axiom 自身或范围外前台切换中断停留，不把该时段算在之前应用。
- 本地建议：重复相继启动、系统事件后重复启动、重复退出收尾、窗口显示后重复整理可进入暂停草稿；前台切换只标证据不足。有次数/机会/代表证据/限制及本地反馈，无因果或节省时间承诺。可在观察中或结束后补充/清空本次目的，不改变事件或重启记录。
- 离线 AI：64 KiB 版本化匿名摘要与提示词，先预览删减再复制；不上传、不需 API Key。严格校验导入结构/版本/能力/组合/参数/对象，自由文本执行参数拒绝；用户确认后进入未保存的暂停草稿。
- 源码扩展：确认需求后生成结构化开发任务包；实际注册生成 JSON/可读能力目录；真实 `window.state` 示例串联声明、编译、Provider、原生实现与验证。无动态 DLL 执行。

退出观察默认不选中，只跟踪本次或继续观察后新核验的当前用户进程；共享启动源，最多 128 个并发句柄等待，无轮询，暂停/结束释放全部。遗漏短进程或权限失败报告缺口，进程退出来源未知。重复退出候选仅请求正常关闭配套程序最新实例，默认暂停、不强杀、不自动重开。句柄跟踪、容量、取消和异常回归已接核心；实际 WMI 通知与进程退出联动待 Windows 桌面实测。

窗口观察新增显示/隐藏/最小化/最大化/还原，与规则/命令共享窗口源，默认关闭；初始状态仅为基线，不采标题或位置坐标。窗口移动但布局类别未变只做轻量核对，不重复读进程元数据。重复显示后整理可生成带多窗口/来源限制的暂停草稿。任意位置/尺寸及设备环境关联仍未实现。

Windows 回归进一步发现进程退出等待注销与句柄关闭之间的竞态；取消/结束现在用不拥有进程句柄的等待包装，并等待线程池注销完成再关闭自己的句柄，避开 CLR 等待数组延迟释放引用；不删除句柄释放断言。原生回归及最终包仍以当前提交 CI 为准。

原生窗口观察准确暴露“最大化后最小化”的 Windows 还原语义：首次还原会回到最大化。还原普通窗口和布局动作现按同一期限分两步处理，逐步核对窗口身份；原生测试强化覆盖这条真实路径，观察保持如实记录中间最大化。

观察现可识别当前显示器工作区的近似左半屏、右半屏和中央 80%，保留类别不保留精确坐标/显示器标识。重复显示后摆放进入同一证据建议和暂停草稿流程；允许 DPI 边框误差，动作按触发时的显示器执行。里程碑 `e1c182c` 已通过双平台 190 核心、20 原生回归与完整构建，并生成带来源信息的私有包；布局增量需新提交 CI，不能以旧包替代。
