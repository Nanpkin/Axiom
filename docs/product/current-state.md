# 当前状态与交接

更新：本轮云端迭代。当前是持续变化的小型 Windows 11 x64 自动化工具，HDR 只是第一个场景。源码以此可用版本重新开始 Git 历史；个人现场记录和原始验收证据只留本机，不作为云端必读资料。

## 入口与架构

- 本机预览：artifacts/Axiom-preview/Axiom.exe；分发包：artifacts/release。源码仓库不包含二进制，按 [分发说明](../development/distribution.md) 构建。
- 根目录 Native AOT 启动器；app 中的 Host/Session Agent/WinUI 共用自带运行库。Host 是 Service 角色，尚未注册 Windows Service。UI 完全退出后后台继续工作。
- 用户数据在 USERPROFILE 下的 .axiom，配置通过 Host/SQLite 写入。开发与正式入口访问同一数据根；不自动备份、不启用 EFS，不播种或恢复某位开发者的规则。
- 同账户 UAC 提权，登录为当前用户最高权限交互任务；安装版当前用户安装，有开始菜单、可选桌面入口及系统卸载登记。卸载保留数据，只清本安装所属登录任务。
- 按 [代码定位表](../development/code-map.md) 阅读本轮相关代码，边界见 [架构地图](../../ARCHITECTURE.md)。旧计划不是执行指令。

## 关键语义

- 批量打开`open-target.batch`1–8项，每行类型及目标合计最多255字符；仅本机目录、白名单文档及无凭据http(s)，无程序/脚本/快捷方式/含宏文档、网络共享/映射驱动器或自定义协议。全部配置与可访问性先预检，再逐项顺序请求；共用原`target.open`单准入和整批8秒。失败/取消/超时停止后续，回执只计数及项序号；正在发送项可能已受理未确认。不保证载入，不回滚/关闭/重试；原单目标语义不变。AI仅空名单待手填，延迟校验不放松。
- 前台窗口`window.foreground-layout`仅快捷键，无exe/HWND/延迟参数。共享窗口事件先订阅、再捕获执行开始一个可见、无拥有者顶层窗口并固定SID/会话/进程创建身份，排除Axiom、桌面、任务栏/对话框；销毁、切走或身份Unknown即停止，不找同应用其他窗口。每次写前核验，必要时一次还原、布局读回，5秒单准入/3秒事件确认，无轮询/重试/恢复；超时后未完原生工作继续持有事件租约。可能已还原或移动，窗口限制大小/位置会失败或未确认，原完整路径窗口命令不改。
- 当前媒体状态按需共享GSMTC CurrentSessionChanged及PlaybackInfoChanged，无轮询。先订阅再读当前会话、代际与原生身份核验，旧会话回调丢弃；首次/切换/Unknown恢复仅基线。无会话不冒充暂停/停止，访问/查询/通知故障保持Unknown并释放持续动作；末消费者在原线程注销，阻塞清理不创建第二工作线程。不采应用ID、曲目或音频内容。
- 相对播放音量`audio.playback-adjust`提高/降低1–100整数百分点，默认5，限制0–100%；仅组合快捷键或指定时段间隔。执行开始绑定常规默认播放设备，已知有限0–1音量才一次写入读回，保留静音，不影响单独路由。不转而操作新默认设备；外部修改可能交错，读回不一致失败，无持续压制或恢复/重试。
- 麦克风切换`audio.microphone-toggle`只接受延迟，对执行开始默认通信输入GetMute反向SetMute后读回，未知初态不写。原`audio.microphone`含义/schema不变；不改增益/应用路由、不录音，不是硬件隐私开关，取消静音可能恢复收音。两新动作共享原5秒单准入，取消/超时可能已写，暂停不恢复。
- 程序优先级`program.priority`多选1–32完整exe路径，低于正常/正常/高于正常；执行时捕获同用户同会话实例，固定句柄/创建时间/路径/SID核验，写后读回。目标缺失、权限、身份未知或读回失败明确报告，可能部分完成。不是CPU占用限制，不启动或预设未来实例；条件结束、暂停和取消不恢复已写值，不自动重试。
- 屏幕关闭`display.off-request`仅组合快捷键/系统事件，核验当前token SID和WTS活动会话，已锁定也可请求。一次自有隐藏窗口`SC_MONITORPOWER`请求，5秒单准入有界等待；成功仅为系统接受，不证明物理关闭。不锁屏、不睡眠、不改电源方案或持续保持唤醒；输入、驱动和保持屏幕唤醒请求可能影响效果，暂停不能撤销已发请求，不恢复或重试。
- 通用时段限制适用于声明支持的一次性命令：选星期、本地开始/结束，可跨午夜并归开始星期；时段外新边沿、延迟到期或排队取出直接跳过，开窗不补执行、不额外轮询，已开始动作不撤回。含限制任务使用schema 2，旧后端拒绝而非丢弃限制；HDR和保持唤醒尚不支持此门禁。
- 内置亮度动作只处理执行时可核验内置连接、活动状态及WMI可写接口的面板，0–100整数，一块一次写入并读回；外屏DDC/CI不在范围。未知/重复身份或缺接口不尝试写入，无支持面板失败；多面板部分完成不能回滚。新亮度保留，暂停、条件结束或接电不恢复；取消/超时可能已写入，不重试。驱动、自适应亮度或厂商软件可能改变后续效果。
- 默认设备静音检测可选通信输入或常规默认播放、已静音/已取消静音。共享MTA按需订阅端点音量回调，回调仅排入有界提示，之后GetMute核验；默认选择变化即建基线，即使短暂换回同一设备也不补Command，普通设备清单通知同身份不重绑。设备缺失/失效或通知/查询失败为Unknown，持续动作释放；消费者队列积压失效后丢弃缓冲Known，不补触发历史Command且不结束其他消费者。共享工作提示溢出立即使消费者Unknown，不等待阻塞的COM查询或注销返回；消费者释放最多等待5秒，实际COM注销仍由原MTA完成。18项针对性核心回归及PR #2 Windows原生检查通过；已包含在当前main，实机验收待完成。不录音、不代表应用路由或硬件隐私，设备标识仅进程内短暂比较。
- 供电条件可选接电、电池供电、电池供电且低于1–99自选阈值；严格低于，接电结束低电条件。共享供电/电量原生通知，最多64提示合并后只读当前状态，无周期查询。电量255、供电未知、查询失败或矛盾的无电池供电状态保持相关Unknown；无电池不当低电。首次、睡眠恢复及Unknown后恢复只建立Command基线，已知初始条件可持有保持唤醒请求。
- 电源方案动作只选择标准平衡/节能/高性能；执行时先枚举确认方案实际存在，再一次切换并读回，不创建、导入或修改内部设置，也不操作Windows电源模式滑块。方案缺失/权限或策略拒绝明确失败；5秒有界执行，取消可能已切换，暂停/条件结束不自动恢复。Modern Standby可能仅提供平衡方案。
- 保持唤醒持有Axiom自己的Windows Power Request；系统或系统及屏幕可选，同类规则共享，最后条件结束、Unknown、暂停、删除、观察释放及连接断开收回。不改电源计划，不撤销别的软件请求；初始已成立条件属于Desired状态，可直接申请。仅证明请求存在，不能保证系统策略或用户手动睡眠被阻止。租约异常不在同一条件代际自动重试。
- 应用音量多选1–32完整exe路径；仅处理执行开始默认播放设备上、经SID/会话/进程身份核验的全部匹配活动会话，写后读回。未播放、没有会话或身份未知明确失败/部分完成，不预设未来会话，不改变设备主音量或其他应用；5秒有界原生入口与现有音频动作共享，取消/超时可能已写入，不自动恢复。
- Wi-Fi检测按用户手工填写的本机配置文件名多选（最多16），区别于SSID和互联网连通性；按需共享Wlan通知，多网卡任一匹配连接/全部确认未连接，未知不当断开，首次/恢复基线不补触发。无硬件、服务或查询/权限失败明确未知；不记录SSID、地址、密码。名单使用应用内弹窗，完整本地名称不进入匿名摘要。
- 精确USB检测手工复制设备管理器的完整`USB\\设备\\实例`路径，最多16项，大小写不敏感整项匹配。只核验当前`GUID_DEVINTERFACE_USB_DEVICE`接口对应实例，不猜HID/USBSTOR子功能、父设备、型号或容器。共享原生类别通知，64项有界合并后SetupAPI查询；无接口是已知空，任一查询失败、通知丢失或超出256接口为Unknown，不能假移除。首次/重连、睡眠恢复及未知后恢复仅建立一次性动作基线；任一目标存在可持续保持唤醒，结束或未知释放。完整实例可能含序列号，仅本地保存，不新增主动观察身份记录，匿名目录清理名单默认值，AI导入只能留空待手填。
- 窗口移屏只选执行时主屏、上一屏或下一屏；屏幕按桌面横坐标/纵坐标排序循环，不保存设备身份。完整路径/SID/会话/进程创建时间核验后，每个目标仅一个可见主窗口，最小化/最大化先还原，移动至目标工作区中央80%并读回。仅一屏时上/下一屏跳过且不改变窗口；拓扑变化、窗口身份或读回异常返回未确认，可能已还原/移动，不自动重试或恢复旧坐标。混合DPI、负坐标和实际多屏仍须实机验收。
- 锁屏动作仅请求当前后台所在、活动交互且已确认未锁定的会话。执行前读取WTS连接/锁状态，不读取账号名；已锁定、非活动或Unknown拒绝。Windows接受`LockWorkStation`请求不证明锁定已完成；取消/超时无法撤销已接受请求，不自动解锁或重试。支持一次性时段门禁，模板须审阅并显式启用；不能把Wi-Fi/USB存在或缺失当安全身份凭据。
- 窗口最小化仍算可见；全部所选程序都没有可见主窗口才成立“全部消失”。未知身份不当作消失，隐藏不等于进程退出或手动关闭；首次/重连不补发旧边沿。
- 窗口状态检测每条规则多选1–32完整exe路径，选最小化/最大化/普通；任一匹配可见顶层无拥有者主窗口满足即成立，隐藏或不存在不算普通。文件名仅排除明显无关进程，最终核验完整路径/SID/会话、固定进程句柄、创建时间/存活及HWND所属PID。已知满足优先于未知，只有可能匹配的未知窗口影响对应状态；首次/Unknown恢复只建立Command基线，已知初始Desired可生效。共享WinEvent先订阅后一次枚举，最多256已排队HWND去重后读当前状态、无周期扫描；最多128订阅资源/4096相关窗口，溢出或源故障转Unknown且不自动重试。新增最小化通知注册失败仅拒绝新检测，不使既有窗口动作/出现检测失效。短暂往返可能合并，最大化不证明全屏或手动操作；不与窗口状态/移屏动作组合，避免自身反馈。
- 显示数量条件`display.count`选择至少/恰好1–16个Windows逻辑桌面显示器，区别于物理屏幕数或特定设备。复用隐藏消息窗口的显示变化/恢复通知，64提示合并后一次`EnumDisplayMonitors`查询服务最多32条件，无轮询、不保留屏幕ID/坐标。只有完整1–64计数才Known，空/失败/超限/通知丢失为Unknown；首次、睡眠恢复及Unknown恢复只建Command基线，已知初始Desired可保持唤醒。镜像/RDP/虚拟显示器可能不同于物理数量，窗口动作执行前仍自行核验拓扑。
- Internet条件`network.internet-state`选择Windows报告可用/不可用，复用按需Network List Manager原生通知后读取当前IPv4/IPv6 Internet标志，不做ping/HTTP探测或周期查询、不采网络名称/地址/位置/设备身份。明确本地网络/断开才可判不可用，服务/订阅/查询失败或不识别标志为Unknown；源/队列失效立即标故障，丢弃已缓冲Known并先发布Unknown再清理。首次/重新启用/Unknown恢复只建Command基线，已知持续条件可保持唤醒，结束/未知/暂停释放。VPN/NCSI策略可能影响报告，不保证任意网站或目标应用可达，也不证明网络可信。
- 本次新进程退出最多128个并发句柄等待，暂停/结束释放；短进程、权限失败报告缺口。窗口和退出范围默认未选，不采标题/按键正文/剪贴板/截图/命令行。范围外前台中断停留。
- 布局观察只保存当前工作区的近似左右半屏/中央类别，无坐标或显示器标识；显示模式通知不保证覆盖所有插拔，不能识别特定屏幕组合。建议保留这些限制，命令一次操作，不恢复旧布局。
- 低电量仅连续已知读数向下穿越20%/10%时触发；初始、未知后不补发，升至阈值以上才重新触发，不区分各块电池或限制供电方式。
- 原系统事件与主动观察的任意USB接入/移除仍只读类别通知，不记录设备路径/序列号，也不随精确检测增加身份采集。复合设备或系统重枚举可能多次，不证明手动插拔；该类别检测和建议仍不能筛选特定设备。精确实例检测是独立规则能力，边界见上文。
- 默认音频变化使用独立共享 `IMMNotificationClient`，不枚举设备或读取标识；观察范围单独选择、默认关闭。只覆盖常规默认播放角色与默认通信麦克风，不证明应用实际路由或具体设备。音频通知不可用时相关规则标未知，其他Provider继续；检查音频服务后暂停重启该检测。
- 播放音量动作绑定执行开始时的默认播放设备，一次设音量/静音/取消静音并读回；只改选定设置，不持续控制、不中止播放、不动麦克风、不自动恢复。无设备/读回不一致明确失败；原生调用5秒未返回报告结果未确认，保留串行占用直到真正结束，拒绝新动作而不堆线程。取消/超时可能已写入，不重试或反向恢复。
- 打开目标支持本机目录、限定扩展名的文档/图片及http(s)网页。文档仅以open动词交给默认关联，不传参数、不读内容、不保证载入；不支持程序/脚本/快捷方式/含宏Office扩展名、UNC、映射网络驱动器或备用数据流。路径仍须手工补齐；这不是文档内容或默认关联的安全检查。Shell请求使用单准入后台线程，8秒未返回标未确认，取消后仍保留准入直到原生返回，不补发或自动重试。
- 桌面提醒只请求Windows通知区域显示文字，默认不请求声音；同一会话串行、不排队、临时图标至多约10秒。勿扰/锁屏可能隐藏，成功只代表系统接受请求、不代表已读；点击不执行内容。暂停取消尚未发出的请求，不能保证撤回已显示通知。
- 麦克风动作只改执行开始时默认通信输入设备的静音状态，不改输入增益、不自动恢复；模板默认只静音，取消静音是明确选择。应用自选的其他输入设备不受保证，不是硬件隐私开关、不停止录音程序，真实收音需在目标应用核对。与播放操作共用有界原生入口。
- 周期检测使用单调时钟和一个最近到期计时器，同周期共享资源，无环境轮询。首次等待完整周期；暂停/重启/检测重连后重新计时；挂起后每个周期至多一次，不追赶遗漏次数、不唤醒电脑，不是每天固定钟点。
- 时段内定期检测按选定星期的时段起点加间隔计算本地钟点，首个机会为开始后一个间隔，结束时刻排除；跨午夜按起点星期归属。只等未来机会，错过不补发、重复DST钟点取第一次；延迟回调最多一分钟且仍须在时段内。只限制这个检测，不限制其他规则或撤回动作，动作延迟可能跨过结束；默认工作日9–18点每30分钟。
- 固定钟点按Windows当前本地时区与多选星期，只等未来时刻；时钟/设置变化和恢复后重算，不补发错过时刻。一分钟以内调度延迟可执行，夏令时缺失跳过、重复小时只取第一次；同一订阅内已执行日期不重发，重启不保存此日期。无假日判断、无唤醒电脑。
- 单次定时填写年月日与本地时刻，过期/夏令时缺失不补发；到期状态与动作成功分开显示，执行后规则保留供暂停/删除。时区变更重算尚未结束的日期；同一订阅已结束不重发，重启不持久化结束状态，日期/时区回拨后重新订阅可能再次到期。远期deadline按系统计时器上限分49天块，无环境扫描。
- 文件到达检测按用户填写的目录监听新建/重命名，仅扩展名筛选、非递归、无初始扫描；首个事件起一秒合并为一次。最多16种目录/类别组合，同目录共享通知；不读取内容、不证明下载完成、不传文件名给动作，也不纳入主动观察。UNC/映射网络驱动器不支持；移动目录后需更新路径并重启检测。文件通知故障只令文件检测未知，其他能力继续。
- 相关性不是因果，不能声称节省时间。缺口、重新显示或Axiom动作等中断相关序列；已知Axiom动作目标排除。接受只进入编辑器，正常关闭候选不强杀、不自动重开。
- 完整路径/本机对象映射留本地；匿名别名为每次观察的随机值。导出和任务包均不自动上传；导入不执行代码、URL或自由形式指令，仍须通过参数/能力/组合/对象检查。必须手工选择的目录/网址/显示器允许空占位，确认页列出待填项；正常保存/编译仍严格要求补齐，非空自由路径/设备值不接受。

## 本批电源方案上下文

用户可在通用编辑器选择“当前Windows电源方案”并组合亮度、音量、提醒、打开工具或保持唤醒，保存后独立暂停/启用；“使用标准节能方案后调暗内置屏幕”模板默认暂停。首次已成立可建立Desired请求，一次性动作只响应新边沿；结束、Unknown、暂停或停止收回Desired。UI退出仍由Session Agent检测。

公开GUID_ACTIVE_POWERSCHEME通知为提示，64有界合并后一次PowerGetActiveScheme并LocalFree，无轮询或电源写入。有效自定义GUID是已知false；空GUID、读取失败、畸形通知/挂起为Unknown，恢复仅建基线。新注册失败仅拒新消费者，新消息不形成旧供电/电量动作边沿；队列溢出只使对应租约未知。4项合成状态/Provider/Engine/保存与严格导入检查，以及Agent/Provider交叉构建通过。新增Windows原生只读查询/自有窗口过滤与旧共享过滤复跑交由Windows CI；实际方案/策略/挂起恢复待设备验证，不称实机通过。
