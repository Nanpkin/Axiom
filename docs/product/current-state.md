# 当前状态与交接

更新：本轮云端迭代。当前是持续变化的小型 Windows 11 x64 自动化工具，HDR 只是第一个场景。源码以此可用版本重新开始 Git 历史；个人现场记录和原始验收证据只留本机，不作为云端必读资料。

## 入口与架构

- 本机预览：artifacts/Axiom-preview/Axiom.exe；分发包：artifacts/release。源码仓库不包含二进制，按 [分发说明](../development/distribution.md) 构建。
- 根目录 Native AOT 启动器；app 中的 Host/Session Agent/WinUI 共用自带运行库。Host 是 Service 角色，尚未注册 Windows Service。UI 完全退出后后台继续工作。
- 用户数据在 USERPROFILE 下的 .axiom，配置通过 Host/SQLite 写入。开发与正式入口访问同一数据根；不自动备份、不启用 EFS，不播种或恢复某位开发者的规则。
- 同账户 UAC 提权，登录为当前用户最高权限交互任务；安装版当前用户安装，有开始菜单、可选桌面入口及系统卸载登记。卸载保留数据，只清本安装所属登录任务。
- 按 [代码定位表](../development/code-map.md) 阅读本轮相关代码，边界见 [架构地图](../../ARCHITECTURE.md)。旧计划不是执行指令。

## 关键语义

- 通用时段限制适用于声明支持的一次性命令：选星期、本地开始/结束，可跨午夜并归开始星期；时段外新边沿、延迟到期或排队取出直接跳过，开窗不补执行、不额外轮询，已开始动作不撤回。含限制任务使用schema 2，旧后端拒绝而非丢弃限制；HDR和保持唤醒尚不支持此门禁。
- 内置亮度动作只处理执行时可核验内置连接、活动状态及WMI可写接口的面板，0–100整数，一块一次写入并读回；外屏DDC/CI不在范围。未知/重复身份或缺接口不尝试写入，无支持面板失败；多面板部分完成不能回滚。新亮度保留，暂停、条件结束或接电不恢复；取消/超时可能已写入，不重试。驱动、自适应亮度或厂商软件可能改变后续效果。
- 默认设备静音检测可选通信输入或常规默认播放、已静音/已取消静音。共享MTA按需订阅端点音量回调，回调仅排入有界提示，之后GetMute核验；默认选择变化即建基线，即使短暂换回同一设备也不补Command，普通设备清单通知同身份不重绑。设备缺失/失效或通知/查询失败为Unknown，持续动作释放；消费者队列积压失效后丢弃缓冲Known，不补触发历史Command且不结束其他消费者。共享工作提示溢出立即使消费者Unknown，不等待阻塞的COM查询或注销返回；消费者释放最多等待5秒，实际COM注销仍由原MTA完成。18项针对性核心回归及PR #2 Windows原生检查通过；已合入main e2602f9，尚未发布，实机验收待完成。不录音、不代表应用路由或硬件隐私，设备标识仅进程内短暂比较。
- 供电条件可选接电、电池供电、电池供电且低于1–99自选阈值；严格低于，接电结束低电条件。共享供电/电量原生通知，最多64提示合并后只读当前状态，无周期查询。电量255、供电未知、查询失败或矛盾的无电池供电状态保持相关Unknown；无电池不当低电。首次、睡眠恢复及Unknown后恢复只建立Command基线，已知初始条件可持有保持唤醒请求。
- 电源方案动作只选择标准平衡/节能/高性能；执行时先枚举确认方案实际存在，再一次切换并读回，不创建、导入或修改内部设置，也不操作Windows电源模式滑块。方案缺失/权限或策略拒绝明确失败；5秒有界执行，取消可能已切换，暂停/条件结束不自动恢复。Modern Standby可能仅提供平衡方案。
- 保持唤醒持有Axiom自己的Windows Power Request；系统或系统及屏幕可选，同类规则共享，最后条件结束、Unknown、暂停、删除、观察释放及连接断开收回。不改电源计划，不撤销别的软件请求；初始已成立条件属于Desired状态，可直接申请。仅证明请求存在，不能保证系统策略或用户手动睡眠被阻止。租约异常不在同一条件代际自动重试。
- 应用音量多选1–32完整exe路径；仅处理执行开始默认播放设备上、经SID/会话/进程身份核验的全部匹配活动会话，写后读回。未播放、没有会话或身份未知明确失败/部分完成，不预设未来会话，不改变设备主音量或其他应用；5秒有界原生入口与现有音频动作共享，取消/超时可能已写入，不自动恢复。
- Wi-Fi检测按用户手工填写的本机配置文件名多选（最多16），区别于SSID和互联网连通性；按需共享Wlan通知，多网卡任一匹配连接/全部确认未连接，未知不当断开，首次/恢复基线不补触发。无硬件、服务或查询/权限失败明确未知；不记录SSID、地址、密码。名单使用应用内弹窗，完整本地名称不进入匿名摘要。
- 精确USB检测手工复制设备管理器的完整`USB\\设备\\实例`路径，最多16项，大小写不敏感整项匹配。只核验当前`GUID_DEVINTERFACE_USB_DEVICE`接口对应实例，不猜HID/USBSTOR子功能、父设备、型号或容器。共享原生类别通知，64项有界合并后SetupAPI查询；无接口是已知空，任一查询失败、通知丢失或超出256接口为Unknown，不能假移除。首次/重连、睡眠恢复及未知后恢复仅建立一次性动作基线；任一目标存在可持续保持唤醒，结束或未知释放。完整实例可能含序列号，仅本地保存，不新增主动观察身份记录，匿名目录清理名单默认值，AI导入只能留空待手填。
- 窗口移屏只选执行时主屏、上一屏或下一屏；屏幕按桌面横坐标/纵坐标排序循环，不保存设备身份。完整路径/SID/会话/进程创建时间核验后，每个目标仅一个可见主窗口，最小化/最大化先还原，移动至目标工作区中央80%并读回。仅一屏时上/下一屏跳过且不改变窗口；拓扑变化、窗口身份或读回异常返回未确认，可能已还原/移动，不自动重试或恢复旧坐标。混合DPI、负坐标和实际多屏仍须实机验收。
- 锁屏动作仅请求当前后台所在、活动交互且已确认未锁定的会话。执行前读取WTS连接/锁状态，不读取账号名；已锁定、非活动或Unknown拒绝。Windows接受`LockWorkStation`请求不证明锁定已完成；取消/超时无法撤销已接受请求，不自动解锁或重试。支持一次性时段门禁，模板须审阅并显式启用；不能把Wi-Fi/USB存在或缺失当安全身份凭据。
- 窗口最小化仍算可见；全部所选程序都没有可见主窗口才成立“全部消失”。未知身份不当作消失，隐藏不等于进程退出或手动关闭；首次/重连不补发旧边沿。
- 窗口状态检测每条规则多选1–32完整exe路径，选最小化/最大化/普通；任一匹配可见顶层无拥有者主窗口满足即成立，隐藏或不存在不算普通。文件名仅排除明显无关进程，最终核验完整路径/SID/会话、固定进程句柄、创建时间/存活及HWND所属PID。已知满足优先于未知，只有可能匹配的未知窗口影响对应状态；首次/Unknown恢复只建立Command基线，已知初始Desired可生效。共享WinEvent先订阅后一次枚举，最多256已排队HWND去重后读当前状态、无周期扫描；最多128订阅资源/4096相关窗口，溢出或源故障转Unknown且不自动重试。新增最小化通知注册失败仅拒绝新检测，不使既有窗口动作/出现检测失效。短暂往返可能合并，最大化不证明全屏或手动操作；不与窗口状态/移屏动作组合，避免自身反馈。
- 显示数量条件`display.count`选择至少/恰好1–16个Windows逻辑桌面显示器，区别于物理屏幕数或特定设备。复用隐藏消息窗口的显示变化/恢复通知，64提示合并后一次`EnumDisplayMonitors`查询服务最多32条件，无轮询、不保留屏幕ID/坐标。只有完整1–64计数才Known，空/失败/超限/通知丢失为Unknown；首次、睡眠恢复及Unknown恢复只建Command基线，已知初始Desired可保持唤醒。镜像/RDP/虚拟显示器可能不同于物理数量，窗口动作执行前仍自行核验拓扑。
- Internet条件`network.internet-state`选择Windows报告可用/不可用，复用按需Network List Manager原生通知后读取当前IPv4/IPv6 Internet标志，不做ping/HTTP探测或周期查询、不采网络名称/地址/位置/设备身份。明确本地网络/断开才可判不可用，服务/订阅/查询失败或不识别标志为Unknown；源/队列失效立即标故障，丢弃已缓冲Known并先发布Unknown再清理。首次/重新启用/Unknown恢复只建Command基线，已知持续条件可保持唤醒，结束/未知/暂停释放。VPN/NCSI策略可能影响报告，不保证任意网站或目标应用可达，也不证明网络可信。
- 本次新进程退出最多128个并发句柄等待，暂停/结束释放；短进程、权限失败报告缺口。窗口和退出范围默认未选，不采标题/按键正文/剪贴板/截图/命令行。范围外前台中断停留。
