## 所有者的持续要求与当前主线

2026-10-09 所有者再次明确：四阶段最小闭环已接通，当前回到**大量提出并开发真正有用的检测能力与动作能力**。先忽略已完成的阶段任务，主动发现 Windows 日常重复操作的痛点并交付新能力；建议排序、观察细节和界面零碎完善不继续占据开发主线。提醒、观察、建议与源码扩展只做新能力确实需要的接入或已有缺陷修复。

持续推进，不因一个阶段、测试、提交或 PR 结束而停下。所有目标、头脑风暴、实施顺序、API 障碍与交接必须留在仓库，不能只留在聊天中。已授权范围内自主实现与验证，每个有意义且完成相关验证的增量及时 commit/push；有实质阻塞则记录证据并继续其他独立能力。模块数、测试数、文档数量不能代替用户新增能完成的事情。所有者最新接续要求最小必要验证，保持断言与约束，不反复扩充测试或框架；负责人只监督，代理实施。

四阶段产品路径仍有效：实用 Windows 自动化 → 用户主动开启的限时、低敏感本地观察 → 有证据的可审阅建议及无需 API Key 的离线 AI 辅助 → 用户确认的源码功能扩展任务。它们已是可复用路径，不能继续被当成待建地基。确定性引擎执行规则，AI 不参与运行时；关闭 UI 后规则继续、主动观察结束。未知不能当作否定，Axiom 自身动作不能冒充用户习惯。所有者最新授权验证后更新main并发布阶段Release；负责人只监督协调、代理实施。保留准确提交对应的便携版、安装版，不替换所有者现场。
