# 未来远程控制边界

V1 和第一阶段都不实现 Web/Remote。正常模式下默认没有监听端口、Web 宿主、发现广播、远程心跳或后台连接；不能为了“以后方便”预先启动空服务器。

未来入口只是已有 Engine 应用操作的鉴权适配器：远程请求 → 身份/权限/scope 校验 → 已存在的 Capability/配置操作 → 同一仲裁、Override、模式和审计。不能绕过 Engine、直接访问 SQLite/Provider，也不能提供任意 PowerShell/CMD、脚本上传执行或任意程序启动接口。

未来实现前必须新增远程安全 ADR：认证、传输保护、凭据保存/撤销、速率限制、防重放、请求幂等、可见开启状态、断网/重连、最小操作许可。远程权限不得比对应本地授权更宽。

轻量模式默认停止远程功能；仅用户明确设置保持例外才允许继续，并显示额外资源成本。是否可远程切换模式及冲突行为须单独定义；远程客户端不能给自己授权 KeepRemoteInLightweight。没有远程组件时该例外仅是未来 contract，不创建配置空壳或依赖。
