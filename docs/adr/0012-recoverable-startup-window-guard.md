# ADR 0012：显式、有限期且可解除的启动窗口遮蔽

2026-10-28，接受为实验选项。所有者要求Axiom启动HECATE时避免窗口闪现，同时保留原入口再次打开窗口。普通SW_HIDE已正确使用但不能阻止后续显示；跨进程DWMWA_CLOAK在本机被拒；独立Desktop改变托盘与重新打开行为。故为当前需求增加一个原生组件，旧隐藏模式保持不变。

## 决策

- 只扩展program.start的显式`startup-hidden`窗口选项，用户选择后才加载组件。Domain/Engine无Win32或注入依赖，UI仍使用声明字段，Agent通过原程序命令链执行。
- 仅x64桌面程序；不用于游戏/受保护程序。不增加外部任意DLL路径、脚本、跨账户或全局桌面钩子。新进程由Axiom按已校验完整路径直接创建，挂起主线程，初始化加载器并核对系统入口，再加载同一构建的保护组件，确认准备完成后恢复主线程。失败只可结束本次尚未恢复主线程的新进程；恢复后失败、取消不强制结束程序。
- 在目标进程内、窗口创建和显示前设置DWM cloak。应用目录及其子目录延迟加载的窗口插件也处理；系统DLL、message-only及子窗口不作为遮蔽目标。不声称覆盖动态解析创建API、其他进程、任意DII初始化窗口或所有GUI框架。
- 默认最长15秒，用户可选1–20整数秒，给既有40秒程序命令截止保留初始化/恢复时间。首个已遮蔽可见窗口自行隐藏/关闭时提前结束；一个进程内等待句柄和最近截止，不轮询。
- 结束先停止新干预、恢复IAT，再确认窗口隐藏、解除cloak；成功后报告可正常手动打开。延迟消息只移除窗口附加状态，绝不再次隐藏窗口，避免把后来的手动打开覆盖掉。恢复未知报告失败，不能仅因启动请求已发出而报告保护完成。
- 保护期间暂借已有共享原生进程订阅，按SID/会话/完整路径核对再次启动的实例，尝试提前让出并保留其打开意图；结束即释放。极短命启动器可能已退出而无法核对，明确不承诺任意保护期内的点击都可识别。保护结束后不继续拦截手动显示或新窗口。
- 取消触发同一隐藏→解除流程，程序保留；目标挂起或恢复失败不能宣称可打开。截止后应用新弹出的窗口不再受本次保护，不能将此功能宣传为全生命周期禁止GUI。

## 文件与更新

组件以MSVC x64静态CRT构建、随统一包分发。宿主只从程序集目录加载其固定组件；目标加载经SHA256核对的同字节临时缓存副本。副本按内容哈希复用，目标保留DLL引用也不锁住固定预览目录。只尝试清理至多32个旧哈希DLL；仍被目标加载的文件保留，后续按需再清理。不复制用户配置、不建配置备份或每轮预览版本目录。

保护结束后DLL可能仍被目标加载，以避免并发回调/替换窗口过程中的不安全卸载；其IAT已恢复、保护标志关闭、等待线程退出。这个加载引用不代表持续隐藏。不承诺零资源占用，未测CPU数值不称性能达标。

## 验证边界

本机合成窗口验证首次显示前遮蔽、自然隐藏/截止解除、手动打开和新建窗口；HECATE使用其`-startup`参数时，启动临时窗口的显示事件已cloaked，解除后原入口可显示未cloaked主窗口。实际Axiom调用路径及取消另作针对性检查。原始记录仅本机，见[研究记录](../development/window-previsibility-research.md)。未逐帧捕获、未验证耳机硬件效果、x86、多账户、所有Qt版本或广泛应用兼容性。
