# ADR 0006 — 轻量模式是一等架构能力

- 状态：Accepted（用户已确定的方向；本次文档固化）
- 日期：2026-09-26
- 来源：本次明确需求；补充实现默认值见 决策状态（本机历史记录）。

## 背景

用户要求玩游戏时尽量减少后台工作，同时不能偷偷停止明确启用并要求保留的核心自动化。

## 决策

Performance/Lightweight 是同一模式。通过 Engine 计算必要依赖闭包、停止非必要观察器/Provider、暂停非关键日志/统计、降低诊断、抑制获准暂停的低优先自动化、只在容忍范围内延长刷新。Remote/Web 关闭，除非用户显式保留。

## 替代方案与取舍

拒绝仅降低进程优先级冒充轻量模式，拒绝全停 Engine，拒绝按 priority 自动撤销用户保留保证。

## 后果

规则保留标记、模式 generation、共享依赖与切换中的动作均需 contract。新规则保守默认保留；无法削减必要工作时显示例外，不承诺总会下降固定百分比。

## 验证

两模式相同保留输入产生相同核心决策；共享依赖、切换/重启、无计时器泄漏测试；混合负载 benchmark。见 [lightweight-mode](../architecture/lightweight-mode.md)。

## 变更规则

改变本决策须新增 ADR 说明原因、影响与迁移，并标记 supersedes；不得静默改写本条历史。实现参数的细化不自动构成架构推翻，但必须同步相关规范与证据。
