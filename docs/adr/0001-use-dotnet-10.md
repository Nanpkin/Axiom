# ADR 0001 — 使用 C# / .NET 10

- 状态：Accepted（用户已确定的方向；本次文档固化）
- 日期：2026-09-26
- 来源：本次明确需求；补充实现默认值见 决策状态（本机历史记录）。

## 背景

Axiom 需要长期维护的 Windows 桌面后台平台，核心逻辑需要可测试、可注入与清晰类型约束。用户已确定语言和运行时，不在奠基阶段重复选型。

## 决策

采用 C# / .NET 10；Windows 11 x64 为产品目标。Domain/Engine 使用与 Windows 无关的核心目标，Windows 适配器/宿主使用所需平台目标。SDK patch 在首个开发里程碑核实和固定，WinUI/Windows App SDK 具体版本后续验证。

## 替代方案与取舍

不改用其他语言、旧版 .NET 或脚本堆叠作为核心。NativeAOT、额外 runtime 与复杂源生成不是当前承诺；仅在证据充分时再决策。

## 后果

管理运行时的分配/GC、启动和 idle 成本需要实际测量；选择 .NET 不等于自动低 CPU。核心隔离使纯逻辑测试不需管理员或桌面。

## 验证

首阶段 Release build/test；依赖边界测试与 Engine-only baseline。见 首个计划（本机历史记录）。

## 变更规则

改变本决策须新增 ADR 说明原因、影响与迁移，并标记 supersedes；不得静默改写本条历史。实现参数的细化不自动构成架构推翻，但必须同步相关规范与证据。
