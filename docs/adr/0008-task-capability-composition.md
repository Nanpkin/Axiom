# ADR 0008：检测与动作独立描述及编译

状态：Accepted，2026-09-28。用户明确要求通用任务 UI 与相应引擎接口。

## 背景

0010 虽重做页面层次，配置仍围绕 HDR。仅有通用 Engine 内核不足以保证产品扩展性；等待第二场景才抽离表单与协议已被用户明确否定。

## 决策

Domain 定义版本化任务、检测/动作调用和字段描述。Engine 定义独立编译注册及任务后端端口。宿主公开实际接通的兼容组合；UI 根据目录选择并渲染参数，不含具体能力分支。Contracts 引用纯 Domain 类型，不引用 Engine。HDR 作为第一个兼容适配器保留原数据与运行语义。

描述只定义配置，不代表能力已经可以执行；真实观察、权限、持久化和生命周期仍由后端接通。CPU-first、三角色、Command/Desired 和仲裁契约不变。

## 替代与后果

不继续逐场景复制表单；不预先构建动态插件市场或 DAG。新增后端须明确支持组合；暂不支持跨后端原地迁移。字段 schema 是受控扩展点，新增普通能力无需改 UI；新字段种类才扩展渲染器。测试第二组不同能力验证复用，不能据此声称第二真实场景可用。
